# Sistema Integral de Gestión Ambiental LLE V5.6.25

Versión de prueba LAN para PC Gerente/Servidor y PC Técnico/Cliente.

### Servidor
Ejecute `INICIAR_SISTEMA_LAN_V5_6_25.bat` en la PC del Gerente/servidor.

### Cliente Técnico
No necesita Python ni ejecutar BAT. Accede por navegador a la IPv4 del servidor, por ejemplo:
`http://192.168.1.175:8001/01_SISTEMA_INSPECCIONES/`

### Mejoras de esta versión
Ordenamiento visual del Motor de Seguimiento y del módulo Técnico, aislamiento del estado local entre expedientes, retorno a Inicio al finalizar, y visualización clara del componente principal registrado en la Denuncia/Solicitud.
