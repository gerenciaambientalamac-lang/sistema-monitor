# Inicio desde el repositorio

## Windows / LAN HTTPS

Ejecute:

`INICIAR_D06_R1_LAN_HTTPS.bat`

A diferencia de los lanzadores antiguos, este archivo mantiene el servidor en la misma consola. Si el servidor falla, el traceback queda visible y permite diagnosticar el problema.

## Importante

No se incluyen en Git:

- `tls/cert.pem`
- `tls/key.pem`
- `sistema_gestion_ambiental.sqlite3`
- fotografías de ejecución

Estos elementos se generan localmente.
