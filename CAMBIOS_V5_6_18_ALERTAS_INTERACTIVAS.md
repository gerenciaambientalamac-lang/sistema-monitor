# V5.6.18 — Alertas interactivas

## Cambios

1. Al abrir una alerta desde el botón de acción, la bandeja de alertas se cierra automáticamente.
2. Al hacer clic fuera de la bandeja, esta se cierra.
3. Las alertas nuevas muestran un aviso emergente interno (toast) visible aunque la bandeja esté cerrada.
4. Las alertas nuevas generan un aviso sonoro breve mediante Web Audio cuando el navegador permite audio tras interacción del usuario.
5. Se agrega botón “Activar notificación” para habilitar, cuando el navegador lo permita, las notificaciones del sistema; si no se conceden, al menos queda habilitado el sonido.
6. Al pulsar el aviso emergente se abre la actuación relacionada y se cierra el aviso.
7. La bandeja conserva el contador de no leídas y las acciones de marcar una o todas como leídas.
8. Se mantiene la alerta específica para el Técnico y para Gerente/Administrador.

## Nota
Las notificaciones del sistema dependen de los permisos del navegador y las políticas del sistema operativo. El aviso interno en pantalla no requiere permisos.
