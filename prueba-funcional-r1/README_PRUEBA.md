# LA LIBERTAD ESTE — PRUEBA FUNCIONAL R1

## Inicio en Windows
1. Descomprima el ZIP.
2. Entre a la carpeta `prueba-funcional-r1`.
3. Ejecute `INICIAR_PRUEBA.bat`.
4. Se abrira la interfaz en http://127.0.0.1:8001/index.html

## Persistencia de esta prueba
Los datos de la prueba se conservan en el almacenamiento local del navegador. El servidor solo sirve los archivos localmente.

## Flujo
Tecnico: Expediente -> Acta -> Arboles -> Evidencias -> Informe -> Enviar a validacion.
Gerente: Validacion -> Visto Bueno -> tasas -> recibo -> documento.

## Nota
Esta es una prueba funcional independiente. No modifica D06-R1 ni su base de datos.
